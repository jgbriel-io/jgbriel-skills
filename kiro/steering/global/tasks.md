# Tarefas

- Para qualquer trabalho com 3+ passos, usar sistema de tasks/todos.
- Marcar `in_progress` ao começar, `completed` imediatamente ao terminar (não em batch).
- Não inventar tarefas — apenas as dentro do escopo solicitado.

# Memória Persistente

- Salvar aprendizados sobre o usuário, feedback recorrente, decisões de projeto não óbvias.
- **Não** salvar estado efêmero, código, ou coisas deriváveis de `git log`.
- Sempre atualizar índice de memória ao criar novo arquivo de memória.
